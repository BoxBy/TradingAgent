## TradingAgent

국내·해외 주식 시장 데이터를 기반으로 종목을 선별하고 주문을 집행하는 파이썬 기반 자동 매매 프로그램입니다. 
한국투자증권(KIS) API를 사용하여 실거래와 모의투자를 모두 지원하도록 설계되었습니다.

이 저장소는 개인용/연구용 자동 매매 시스템 구축 예시를 제공하며, 실전 운용 전 충분한 검증과 모의 테스트를 전제로 합니다.

---

## 주요 기능

- 계좌 현금/보유 종목 현황을 반영한 **포지션 관리 및 리스크 관리**
- 한국 및 해외 주식 **시세·뉴스·지표 데이터 수집**
- 시장 상황에 따른 **매수/매도 기준(Threshold) 관리**
- 손익, 거래 이력 등을 활용한 **성과 모니터링 및 리포트 생성**
- 슬랙(Slack)을 통한 **알림 및 일일 보고**

구체적인 매매 전략(종목 선정 로직, 기준값 계산 방식 등)은 코드 내부 설정과 환경 설정 파일을 통해 관리되며, 사용 목적에 맞게 변경할 수 있습니다.

---

## 구성 요소 개요

- `src/data_providers/`
  - 한국투자증권(KIS) 및 외부 데이터 공급원(Finnhub 등)과의 연동을 담당합니다.
- `src/core/`
  - 매매 조건 모니터링, 포지션 관리, 기본적인 최적화 로직 등이 포함됩니다.
- `src/orchestrators/`
  - 데이터 수집 → 분석 → 주문 → 모니터링을 하나의 플로우로 묶어 실행하는 진입점 역할을 합니다.
- `src/emergency/`
  - 급등락, 핵심 악재 등 비정상 상황에서의 비상 대응 로직을 포함합니다.
- `src/services/`
  - 과거 거래/분석 기록 저장 및 조회 등 부가 서비스 레이어입니다.
- `src/utils/`
  - 로깅, 알림, 환경 변수 관리 등 공통 유틸리티입니다.

세부 동작은 각 모듈의 주석과 함수 이름 위주로 파악할 수 있도록 구성되어 있습니다.

## 요구 사항

- Python 3.9 이상
- pip를 이용한 패키지 설치 환경
- 한국투자증권(KIS) API 및 기타 외부 서비스용 API 키

외부 서비스 예시:

- 한국투자증권(KIS) API (실계좌/모의투자)
- Finnhub (해외 시세 및 뉴스)
- Slack Webhook (알림/리포트)
- DeepL 등 번역/텍스트 처리용 API (선택)
- Google AI Gemini 등 텍스트 분석 API (선택)

사용하지 않는 서비스는 환경 변수에서 비워두거나 관련 기능을 비활성화하여 운영할 수 있습니다.

## 설치

1. 저장소 클론

```bash
git clone https://github.com/BoxBy/TradingAgent.git
cd TradingAgent
```

2. 의존성 설치

```bash
pip install -r requirements.txt
```
pykis 오류가 발생한다면 [pykis](https://github.com/BoxBy/pykis)를 설치해보시는것을 추천드립니다

## 환경 설정 (api.env)

프로젝트 루트에 `api.env` 파일을 두고 주요 인증 정보를 관리합니다. 예시는 다음과 같습니다.

```dotenv
# Google / 텍스트 분석 API (선택)
GOOGLE_API_KEY_1="..."
GOOGLE_API_KEY_2="..."

# 한국투자증권 실계좌
KIS_APP_KEY="..."
KIS_APP_SECRET="..."
KIS_ACCOUNT_NO="12345678-01"  # 하이픈 포함

# 한국투자증권 모의투자 계좌
KIS_MOCK_APP_KEY="..."
KIS_MOCK_APP_SECRET="..."
KIS_MOCK_ACCOUNT_NO="12345678-01"

# 시세/뉴스 데이터
FINNHUB_API_KEY="..."

# 알림/리포트
SLACK_WEBHOOK_URL="https://hooks.slack.com/services/..."

# 번역 API (선택)
DEEPL_API_KEY="..."
```

운영 환경에 따라 필요한 키만 채워 사용하면 됩니다. `api.env` 파일은 `.gitignore`에 포함되어 있으며 저장소에 커밋되지 않습니다.

## 실행 방법

기본적인 실행은 다음과 같이 파이썬 엔트리 포인트를 통해 수행합니다.

```bash
python run_bot.py
```

실행 시 다음과 같은 작업이 순차적으로 이루어집니다.

1. 환경 변수 및 설정 로드
2. 시장 데이터 및 뉴스 수집
3. 내부 전략 로직에 따른 매수/매도/보유 판단
4. 한국투자증권 API를 통한 주문 전송(또는 모의투자)
5. 거래 결과 및 계좌 현황 로깅, 요약 리포트 전송

실거래에 앞서 반드시 **모의투자 계정**으로 충분히 테스트한 뒤 운영 환경에 적용하는 것을 권장합니다.

## 디렉터리 구조 (요약)

```bash
TradingAgent/
├── data/                    # DB, 캐시 등 데이터 파일 (git 무시 대상)
├── logs/                    # 로그, 리포트, 차트 이미지 (git 무시 대상)
├── rag_database/            # 검색·참조용 로컬 데이터베이스
├── src/
│   ├── agents/              # 시장/종목 분석 로직
│   ├── core/                # 모니터링 및 기본 전략 엔진
│   ├── data_providers/      # 외부 데이터 공급원 연동
│   ├── emergency/           # 비상 상황 대응 로직
│   ├── orchestrators/       # 전체 플로우 조율
│   ├── services/            # 기록/조회 등 서비스 레이어
│   └── utils/               # 공통 유틸리티
├── api.env                  # 환경 변수 설정 파일 (예시)
├── requirements.txt         # 파이썬 의존성 목록
└── run_bot.py               # 실행 엔트리 포인트
```

실제 세부 구조와 파일명은 개발 과정에서 일부 변경될 수 있습니다. 최신 구조는 소스 코드를 직접 확인해 주세요.

## 로그 및 데이터 보관

- `logs/` 디렉터리에는 일별 로그, 성과 요약, 차트 이미지 등이 저장됩니다.
- `data/`, `rag_database/` 등은 뉴스, 분석 결과, 과거 거래 이력을 로컬에 저장하는 용도로 사용됩니다.

운영 환경에 맞게 로그 보존 기간과 데이터 정리 정책을 별도로 두는 것을 권장합니다.

## 주의 사항 및 면책 조항

- 본 프로젝트는 **개인 연구 및 학습용** 예제에 가깝습니다.
- 자동 매매 시스템은 설계 오류, 외부 API 오류, 네트워크 문제 등 다양한 이유로 예상치 못한 손실을 초래할 수 있습니다.
- 실계좌에 적용하기 전, **충분한 백테스트와 모의투자 검증**을 반드시 수행해야 합니다.
- 이 저장소의 코드를 사용하거나 변경하여 발생하는 모든 투자 손실 및 법적 책임은 전적으로 사용자 본인에게 있습니다.
